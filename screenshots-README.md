# Application Screenshots

This directory contains selected screenshots from the Domestic Flight Booking System case study.

The screenshots are organized by workflow so that the repository reflects the application's major user journeys.

## Categories

### Login / Authentication
- Login
- Invalid username
- Invalid password
- Registration
- Forgot password

### Admin
- Admin dashboard
- Manage airlines
- Manage users
- Manage bookings
- Manage flights
- Manage complaints
- Configuration

### Airline
- Airline dashboard
- Schedule flights
- Manage flights

### User
- User dashboard
- Search flights
- View flights
- Manage bookings
- Manage complaints

## Naming convention

Use lowercase names with hyphens, for example:

```text
login.png
invalid-username.png
manage-flights.png
search-flights.png
```

Only screenshots that are actually present in the case-study material should be added. Do not create placeholder images or invent application screens.
